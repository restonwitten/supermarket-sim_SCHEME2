IGNORE: Create a text file of specification descriptions from the Documentation_plain attribute value, a model_element_name serving as the link between the Visual Paradigm version of the model and the specification descriptions file's version.

INPUTS
- vp_xml_file is the Visual Paradigm model, as an XML file.

1. DEFINE DATA AND PROCEDURES FOR THE PUSH
    - sd_block_set is a dictionary where the key is the model_element_name and the associated value is its sd_block text item.
    - xml_element_name comes from each XML element's start tag's Name attribute.
    - documentation comes from each XML element's start tag's Documentation_plain attribute.

    - Template sd_block_template(model_element_name, sd_text) is:
        *** BEGIN SPEC <model_element_name> ***
        <sd_text>
        *** END SPEC <model_element_name> ***

    - Template sd_contract_template(model_element_name) is:
        *** BEGIN CONTRACT <model_element_name> ***
        PURPOSE: <model_element_purpose>
        USAGE_EXAMPLES:
            EXAMPLE_SETUP:
                <example_setup>
            EXAMPLES_OF_NORMAL_USAGE:
                <examples_of_normal_usage>
            EXAMPLES_OF_COUNTER_USAGE:
                <examples_of_counter_usage>

        REQUIRED_ENVIRONMENT:
            <required_environment>
        *** END CONTRACT <model_element_name> ***
   
    - Procedure push_documentation_to_sd(xml_start_tag, model_element_name) is:
       print(f"{model_element_name=}")
       sd_text is documentation
       if sd_text does not contain a "CONTRACT" block then:
           append the merged result of template sd_contract_template(model_element_name) to sd_text 
       sd_block is the merged result of template sd_block_template using (model_element_name, sd_text)
       Append the model_element_name with the sd_block to the sd_block_set.
  

2. NAVIGATE THE VP XML TREE PUSHING DOCUMENTATION TO SPECIFICATION DESCRIPTIONS
    For each xml_class_start_tag as start tag with tag name "Class" under "Models/Model[Name="CD1"]/ModelChildren":
        - class_element_name = xml_element_name
        - push_documentation_to_sd(xml_start_tag: xml_class_start_tag, model_element_name: class_element_name)
        - For each direct child of that Class's <ModelChildren> (attributes, operations, etc.), with key = <ClassName>.<ChildName>

3. OUTPUT
    Provide the sd_block_set as a text file containing the values in alphabetical order of the key to a file named "specification_descriptions.txt" for download.
